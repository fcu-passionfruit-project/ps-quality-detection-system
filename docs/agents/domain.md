# Domain docs

This is a single-context repository.

Before exploring or changing the code, read:

- `CONTEXT.md` at the repository root, when present.
- Relevant ADRs under `docs/adr/`, when present.

If these files do not exist, proceed silently. Create them only when domain terms or architectural decisions need to be recorded.

Use the vocabulary defined in `CONTEXT.md`. If a proposed change conflicts with an ADR, surface the conflict explicitly.
